Caso de estudio principal

Análisis Integral de Ventas E-Commerce

Proyecto integrador que combinó tres etapas del flujo de trabajo de un analista de datos: limpieza y preprocesamiento en Python, consultas SQL variadas para extracción de insights, y construcción de un dashboard de visualización para comunicar los hallazgos.

📋 Descripción

Se trabajó con un dataset de prueba de ventas de e-commerce, aplicando un flujo de trabajo completo de análisis de datos organizado en tres módulos: limpieza y preprocesamiento en Python, consultas SQL para extracción de información relevante y construcción de un dashboard de visualización final.

⚡ Desafío principal

El mayor desafío fue integrar de manera coherente tres etapas distintas del análisis sobre el mismo dataset. Cada etapa tuvo sus propias dificultades: tratar valores nulos y formatos inconsistentes en la limpieza, formular consultas que respondieran preguntas de negocio concretas, y traducir datos técnicos en visualizaciones comprensibles.

💡 Solución propuesta

Se diseñó un flujo de trabajo secuencial en Python: exploración inicial del dataset, limpieza con pandas (imputación de nulos, normalización de tipos y eliminación de duplicados), consultas SQL para responder preguntas clave de negocio —ventas por categoría, productos más rentables, evolución temporal— y finalmente un dashboard con visualizaciones que resumían los principales hallazgos del análisis.

🛠️ Herramientas utilizadas

Python (pandas, numpy, matplotlib, seaborn) como lenguaje principal · SQL para consultas de extracción y análisis · Jupyter Notebook como entorno de desarrollo · Excel para revisión inicial del dataset

📚 Aprendizajes alcanzados

Comprendí que la calidad del dato es el paso más crítico de cualquier análisis. Aprendí a articular múltiples herramientas dentro de un mismo flujo de trabajo, y a formular preguntas de negocio concretas antes de escribir cualquier consulta o visualización.

💻 Habilidades aplicadas

Limpieza y transformación de datos · Análisis exploratorio (EDA) · Consultas SQL (SELECT, WHERE, GROUP BY, JOIN) · Visualización con Python · Pensamiento analítico orientado a negocio · Documentación técnica

✅ ¿Por qué elegí este proyecto?

Porque es el que mejor representa mi recorrido completo como analista en formación. Me exigió integrar Python, SQL y visualización dentro de un flujo coherente, enfrentando decisiones reales sobre los datos en cada etapa. Refleja el trabajo de un Data Analyst Junior en un entorno profesional real.
